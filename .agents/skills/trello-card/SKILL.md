# Trello cards

Use the Languee board or the user-selected board. Identify the intended card without guessing; ask if ambiguous. Inspect the board's actual lists before moving a card. Perform only the requested operation, respect external-action permissions, and report the real card URL and confirmed resulting state. Opening a PR does not invoke this skill.
